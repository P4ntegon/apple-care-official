Contributing
Thank you for your interest in improving the APPLE CARE website.
Before proposing a change, please remember that this repository represents a real business. Do not change business details, prices, warranty terms, service claims, contact information, or staff information without approval from the business owner.
How to contribute
Check existing issues or discuss the proposed change with the maintainer.
Fork the repository.
Create a focused branch for your change.
Make the smallest clear change that solves the problem.
Test the website on desktop and mobile screen sizes.
Check navigation, buttons, form validation, WhatsApp links, and email links.
Submit a pull request explaining what changed and how it was tested.
Code guidelines
Keep the project framework-free unless the maintainer approves a change.
Use semantic HTML and accessible labels.
Keep CSS organized and responsive.
Use readable vanilla JavaScript.
Avoid adding unnecessary dependencies.
Do not commit passwords, API keys, private customer information, or other secrets.
Only add images, fonts, and other assets that may legally be used.
Pull request checklist
[ ] The change has a clear purpose.
[ ] Desktop and mobile layouts have been checked.
[ ] Links and interactive features have been tested.
[ ] No private information or secrets were added.
[ ] Business information and claims have not been changed without approval.
[ ] New assets have appropriate usage rights.
By submitting a contribution, you confirm that you have the right to submit it. A contribution does not automatically grant permission to reuse other parts of this proprietary project.
