# APPLE CARE — iPhone Service & Training Center

A responsive business website for **APPLE CARE**, an iPhone service and training center based in Cox's Bazar, Bangladesh.

The website presents the shop's repair services, technician-training programs, business information, and contact options. Customers can submit repair requests and training applications that are prepared for WhatsApp or email.

> **Independent business notice:** This repository describes the business as represented by its owner. It does not imply that the shop is owned, operated, sponsored, certified, or authorized by Apple Inc. APPLE CARE is not presented here as an Apple-authorized service provider.

## About the project

This is a lightweight, static front-end website built with standard web technologies. It does not require a JavaScript framework, build system, or package installation.

### Website sections

- Hero section introducing the service center
- Repair services and service highlights
- Why choose us and repair-process explanations
- About section
- Team information
- iPhone repair training courses
- Repair booking form
- Training application form
- Contact details and location information
- Floating call and WhatsApp contact links

### Features

- Responsive navigation with a mobile menu
- Scroll-reveal animations
- Repair request form that prepares a WhatsApp message
- Training application form with WhatsApp and email options
- Client-side form validation
- Direct phone, email, WhatsApp, and map links
- Search/social sharing metadata and LocalBusiness structured data
- No framework or build step required

## Built with

- **HTML5** — page structure and content
- **CSS3** — layout, responsive styling, and animations
- **Vanilla JavaScript** — navigation, reveal effects, and form interactions
- **Google Fonts (Inter)** — typography

## Getting started

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/p4ntegon/REPOSITORY-NAME.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

For a local development server, you can use the VS Code **Live Server** extension, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

No `npm install` or build command is needed.

## Deployment

This is a static website and can be hosted on services such as:

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel (static deployment)

For GitHub Pages, open the repository's **Settings → Pages**, choose the deployment source, and publish the site from the selected branch and folder.

## Forms and privacy

The forms use browser-side JavaScript to prepare messages and open WhatsApp or the visitor's email application. This project does not include a server-side database or backend form processor.

Do not enter sensitive personal information into a repair or training request. Review the information in the generated message before sending it.
