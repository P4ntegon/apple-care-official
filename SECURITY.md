Security Policy
Supported project
Security reports are welcome for the current version of this website.
Reporting a vulnerability
Please do not publish sensitive security details in a public issue.
Contact the repository maintainer privately:
GitHub: @p4ntegon
Email: ashikbillahabid07@gmail.com
Include:
A brief description of the issue
Steps to reproduce it
The potential impact
Screenshots or a proof of concept, if safe to share
Please allow reasonable time for the maintainer to investigate before publicly disclosing a vulnerability.
Privacy reminder
The current project is a static front-end website. Its forms prepare messages for WhatsApp or email; they do not provide a private server-side customer database. Do not submit real customer data, passwords, or secrets in public issues or pull requests.
